# Data mentah

Letakkan file input notebook di folder ini:

| File | Fungsi |
|---|---|
| `laptops.csv.xlsx` | Dataset laptop mentah (nama bisa berbeda, notebook membaca file yang di-upload) |
| `daftar_cpu_benchmark_FINAL.xlsx` | Tabel skor benchmark tiap CPU (kolom `CPU`, `CPU_Score`) |
| `daftar_gpu_benchmark_FINAL_BERES.xlsx` | Tabel skor benchmark tiap GPU (kolom `GPU_Search`, `GPU_Score`) |

Catatan: skor tiga GPU (Intel HD Graphics 400, Intel HD Graphics 405, ARM Mali T860 MP4) diisi manual di notebook karena tidak ditemukan di sumber benchmark.
